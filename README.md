# 부산 폐의약품 수거함 찾기

부산광역시 공공데이터(폐의약품 수거함 현황)를 매주 자동으로 받아 지도 페이지를 갱신합니다.

- `index.html`: 실제로 보이는 페이지 (자동으로 만들어짐, 직접 고치지 않음)
- `template.html`: 페이지 디자인 원본 (디자인을 바꿀 때 이 파일을 고침)
- `build.py`: API에서 데이터를 받아 `index.html`을 만드는 스크립트
- `.github/workflows/update.yml`: 매주 월요일 오전 9시에 위 스크립트를 실행하고 사이트에 올림

## 관리할 것
- 공공데이터포털 인증키의 활용 기간이 끝나기 전에 연장하고, 키가 바뀌면 Settings > Secrets and variables > Actions의 `DATA_GO_KR_KEY`를 새 키로 바꿉니다.
- 자동 갱신이 실패하면 GitHub가 메일을 보냅니다. 실패해도 사이트는 마지막으로 성공한 버전이 그대로 보입니다.
- 지도는 카카오맵 JavaScript 키를 쓰며, 카카오 개발자 사이트에 이 사이트 주소가 등록되어 있어야 지도가 뜹니다.
